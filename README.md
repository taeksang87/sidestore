# 출퇴근 시간표 (CommuteTimer)

내가 타는 버스·지하철 시간을 저장해 두고, **다음 차까지 남은 시간**과 **집을 나서야 하는 시각**을 실시간으로 보여주는 iPhone 앱입니다.
Mac 없이 GitHub Actions에서 빌드하고 SideStore로 설치합니다.

## 기능

처음 실행하면 **동해선 퇴근(태화강 → 센텀)** 노선이 들어 있습니다 (Scriptable `동해선 퇴근 위젯 v2`와 같은 데이터, 2026-08-28 개정 시간표 기준).

- 다음 열차와 "N분 N초 뒤 출발" 실시간 카운트다운 (역까지 이동 20분 반영), 센텀 도착 예상 시각
- 준비 시간이 빠듯하면 "⚡ 서둘러야 함", 막차 이후에는 내일 첫차 표시
- 다음 직통열차(ITX-마음 / KTX-이음)와 요금, 신해운대 도착 시 센텀까지 환승 시간·요금
- 출발 시각 날씨(Open-Meteo)와 자전거 이용 판단 (비·강풍·더위·추위)
- 노선을 누르면: 명촌차고지 ⇄ 태화강역 경유 버스 번호표 + 네이버지도 대중교통 길찾기
- 출근 / 퇴근 탭 (오후 1시 기준 자동 전환)
- 평일 / 토요일 / 일요일·공휴일 시간표 따로 저장
- 공휴일에는 왼쪽 위 달력 메뉴에서 오늘만 "휴일 시간표"로 변경
- 시간 입력: `07:05 07:20` 붙여넣기, `0705` 형식, 일정한 간격 자동 채우기, 다른 요일에서 복사
- 시간대별 전체 시간표 (지난 차는 흐리게, 다음 차는 강조)

## 1. GitHub에 올리기

1. https://github.com/new 에서 저장소 생성 (예: `commute-timer`, Public 권장*)
2. 이 폴더의 파일을 모두 올립니다. `.github` 폴더도 꼭 함께 올려야 합니다.
   - git 사용 시:
     ```
     git init -b main
     git add .
     git commit -m "first commit"
     git remote add origin https://github.com/<아이디>/commute-timer.git
     git push -u origin main
     ```
3. 올리면 **Actions** 탭에서 빌드가 자동 시작됩니다 (약 3~5분).

\* Private 저장소도 되지만, 그러면 아이폰에서 Release를 받을 때 GitHub 로그인이 필요하고 macOS 빌드 무료 시간이 더 빨리 소진됩니다. 시간표 데이터는 앱 안에만 저장되므로 저장소에는 개인정보가 없습니다.

## 2. 아이폰에 설치

1. 아이폰 Safari로 저장소의 **Releases** → 최신 빌드 → `CommuteTimer.ipa` 다운로드
2. SideStore 실행 → **My Apps** → 왼쪽 위 **+** → 다운로드 폴더에서 `CommuteTimer.ipa` 선택
3. 설치가 끝나면 홈 화면에 "출퇴근" 앱이 생깁니다.

## 철도 API 연동 (공공데이터포털)

국토교통부 TAGO API로 시간표를 자동으로 받아옵니다.

- **지하철정보** → 동해선 광역전철 태화강 출발 시간표(평일/토/휴일)와, 센텀 시간표를 맞춰 계산한 **실제 도착 시각**
- **열차정보** → 오늘 운행하는 KTX·ITX·무궁화의 출발/도착 시각과 요금 (센텀에 서지 않는 열차는 신해운대 기준 + 환승)

설정 방법:
1. [data.go.kr](https://www.data.go.kr)에서 `국토교통부_(TAGO)_열차정보`, `국토교통부_(TAGO)_지하철정보`를 각각 **활용신청** (자동 승인)
2. 마이페이지 → 개인 API 인증키에서 **일반 인증키(Decoding)** 복사
3. 앱 홈 화면 오른쪽 위 ⚙︎ → 인증키 붙여넣기 → **연결 테스트**
4. 노선을 눌러 **철도 API로 지금 업데이트** (이후에는 앱을 열 때 자동: 직통열차 매일, 시간표 7일마다)

> 실시간 지연 정보가 아니라 공식 운행 계획(시간표) 기준입니다.

## 참고

- 무료 Apple ID로 설치한 앱은 **7일마다 SideStore에서 Refresh**해야 합니다 (SideStore 백그라운드 갱신을 켜 두면 편합니다).
- 무료 계정은 SideStore로 동시에 3개까지 앱을 활성화할 수 있습니다 (SideStore 포함).
- 코드를 수정해 `main`에 push하면 새 Release가 자동으로 만들어집니다. SideStore에서 새 ipa를 다시 설치하면 데이터는 유지됩니다.
- 시간표가 바뀌면 앱에서 노선 → 편집에서 고치면 됩니다. JS 배열(`"05:36", "05:52", …`)을 그대로 붙여넣어도 인식합니다.
